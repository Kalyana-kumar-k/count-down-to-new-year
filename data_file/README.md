# 🎉 New Year Countdown Timer

A simple, responsive real-time countdown web application that calculates and displays the remaining days, hours, minutes, and seconds until the upcoming New Year.

---

## ✨ Features

- **Real-Time Updates:** Automatically refreshes every second using JavaScript `setInterval`.
- **Dynamic Year Calculation:** Automatically detects the current year and sets the target to January 1st of the following year—no manual updates needed.
- **Leading Zero Formatting:** Displays single-digit numbers with a leading zero (e.g., `09` instead of `9`) for a clean digital clock look.
- **Responsive Design:** Adapts smoothly to desktop, tablet, and mobile screen sizes.

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure for the countdown containers (`#days`, `#hours`, `#minutes`, `#seconds`).
- **CSS3** – Responsive layout, typography, and styling.
- **Vanilla JavaScript (ES6)** – Date calculation, time formatting, and DOM manipulation.
